# 🚀 Future Interns Data Analytics Internship

This repository contains all projects completed during the **Future Interns Data Analytics Internship Program**. The internship focused on applying real-world data analytics techniques using SQL, Power BI, Excel, and business intelligence practices to solve business problems and generate actionable insights.

# 📌 Internship Tasks

## 📊 Task 1: Sales Performance Analysis

### Project Overview
The objective of this project was to analyze sales data and identify key business trends, revenue drivers, and performance indicators.

### Work Performed
- Cleaned and transformed raw sales data using SQL.
- Analyzed sales, profit, and quantity KPIs.
- Evaluated category-wise and product-wise performance.
- Identified top-performing and underperforming segments.
- Generated business insights for decision-making.
- Built an interactive Power BI dashboard.

### Key Insights
- Identified the highest revenue-generating product categories.
- Evaluated overall sales and profit performance.
- Analyzed customer purchasing behavior.
- Tracked business growth through KPI metrics.

### Tools Used
- MySQL
- Power BI
- Excel
- GitHub

## 📈 Task 3: Marketing Funnel & Conversion Performance Dashboard

### Project Overview
The objective of this project was to analyze marketing funnel performance, lead generation channels, and customer conversion metrics.

### Work Performed
- Analyzed lead generation sources.
- Evaluated marketing channel effectiveness.
- Measured customer conversion performance.
- Studied lead distribution across business segments.
- Built an interactive Power BI dashboard for business reporting.

### Dashboard KPIs
- Total Leads: 8,000
- Total Customers Converted: 842
- Conversion Rate: 10.53%

### Key Insights
- Organic Search generated the highest number of leads.
- Online Medium emerged as the dominant lead category.
- Home & Decor was the strongest business segment.
- 842 customers successfully converted from 8,000 leads.
- Marketing funnel achieved a healthy 10.53% conversion rate.

### Tools Used
- Power BI
- Excel
- Data Visualization
- GitHub
