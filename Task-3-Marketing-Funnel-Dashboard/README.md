
# Task 3: Marketing Funnel & Conversion Performance Dashboard

## Project Overview
This project was completed as part of the Future Interns Data Analytics Internship.

The objective was to analyze marketing funnel performance and customer conversions using Power BI.

## Tools Used
- Power BI
- Excel
- Data Visualization
- GitHub

## Dashboard KPIs
- Total Leads: 8,000
- Total Customers: 842
- Conversion Rate: 10.53%

## Key Insights
- Organic Search generated the highest number of leads.
- Online Medium is the dominant lead type.
- Home & Decor is the strongest business segment.
- 842 customers converted from 8,000 leads.
- Overall conversion rate is 10.53%.
